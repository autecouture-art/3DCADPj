# 3D CAD Suite

包括的な3D CADアプリケーション - ビューアー、モデリングツール、ファイルコンバーターを統合したWebベースのCADシステム

## 機能

### 1. 3D CADビューアー 👁️
- インタラクティブな3Dビューアー
- CADファイルの読み込みと表示
- カメラコントロール（回転、パン、ズーム）
- グリッドと座標軸の表示/非表示
- オブジェクトの選択と管理

### 2. 3Dモデリングツール 🔨
- 基本図形の作成
  - 立方体
  - 球
  - 円柱
  - 円錐
  - トーラス
- CAD操作
  - 押し出し
  - 回転体
  - ブーリアン演算（結合、減算）
  - フィレット
- スケッチツール
  - 線
  - 円
  - 矩形
  - ポリゴン

### 3. CADファイルコンバーター 🔄
対応フォーマット:
- STL (Stereolithography)
- OBJ (Wavefront)
- STEP (ISO 10303)
- IGES (Initial Graphics Exchange)
- PLY (Polygon File Format)
- FBX (Filmbox)
- glTF (GL Transmission Format)
- DXF (Drawing Exchange Format)

機能:
- 複数フォーマット間の相互変換
- バッチ変換
- 変換進捗の表示
- 変換履歴の管理

### 4. CADツール 🛠️

#### 計測ツール
- 距離測定
- 角度測定
- 体積計算
- 表面積計算
- 重心計算
- バウンディングボックス

#### 解析ツール
- ジオメトリチェック
- 干渉チェック
- 統計情報
- 肉厚解析
- 曲率解析
- ドラフト角度解析

#### エクスポートツール
- STL/OBJ/STEPエクスポート
- 画像エクスポート
- アニメーション出力
- 技術図面出力

#### ユーティリティ
- メッシュ修復
- メッシュ簡略化
- メッシュ平滑化
- 座標系変換
- 単位変換
- バッチ処理

## 技術スタック

- **フロントエンド**: React 18 + TypeScript
- **3Dレンダリング**: Three.js + React Three Fiber
- **状態管理**: Zustand
- **ビルドツール**: Vite
- **スタイリング**: CSS Modules

## セットアップ

### 必要条件
- Node.js 18以上
- npm または yarn

### インストール

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# 本番ビルド
npm run build

# プレビュー
npm run preview
```

## 使用方法

### 起動
```bash
npm run dev
```

ブラウザで `http://localhost:3000` を開きます。

### 基本操作

#### ビューアーモード
1. 「ビューアー」タブをクリック
2. 「CADファイルを開く」ボタンでファイルを読み込み
3. マウスで3Dビューを操作
   - 左クリック＋ドラッグ: 回転
   - 右クリック＋ドラッグ: パン
   - マウスホイール: ズーム

#### モデラーモード
1. 「モデラー」タブをクリック
2. 左側のツールバーから図形を選択
3. クリックして3D空間に配置
4. オブジェクトをクリックして選択・編集

#### コンバーターモード
1. 「コンバーター」タブをクリック
2. 「ファイルを選択」ボタンでファイルをアップロード
3. 変換元と変換先のフォーマットを選択
4. 「変換を開始」ボタンをクリック
5. 完了後、「ダウンロード」ボタンでファイルを保存

#### ツールモード
1. 「ツール」タブをクリック
2. カテゴリ（計測、解析、エクスポート、ユーティリティ）を選択
3. 使用したいツールをクリック

## 開発

### コーディング規約
- TypeScriptの厳格モードを使用
- ESLintルールに従う
- コンポーネントは機能ごとにディレクトリで整理

### 新機能の追加
1. `src/components/`に新しいコンポーネントを作成
2. 必要に応じて`src/store/useAppStore.ts`に状態を追加
3. `src/types/index.ts`に型定義を追加
